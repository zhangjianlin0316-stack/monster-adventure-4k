# 灵兽冒险：翠风之旅 v7（4K 原创收集养成 + 小学数学冲分）

一款完全原创的灵兽收集冒险网页游戏：原生 4K（3840×2160）画布渲染、原创音乐与音效、开放大地图，并把 **1–6 年级数学知识点和竞赛题** 深度融入战斗、捕捉、进化和探索的每一个环节。

**在线游玩：** https://zhangjianlin0316-stack.github.io/monster-adventure-4k/
（也可直接双击 `index.html` 本地打开，无需服务器）

- **灵晶 ◆ 只能靠玩获得，没有任何付费内容**：答题（+2，竞赛题再 +2，快速 +1，5 连对 +10）、每日挑战（5 题答对 3 题 ◆80 + 祈愿券）、开宝箱、收集「灵瞳」（大地图上 14 颗，答对 2 道题收集，每颗 ◆40，每 5 颗送祈愿券）。

- **更生动的战斗**：出场亮相 + 招牌动作、攻击 / 受击 / 暴击 / 低血 / 倒下时会说话；闪避、挑衅、受击被打飞 / 旋转 / 压扁，低血喘气流汗，待机小动作。
- **随机趣味事件**（每场最多 2 次）：天气突变、云游先生出谜题、灵兽斗嘴、幸运转盘（答对伤害翻倍）、斗舞大会、流星雨数一数——多数和数学题绑定。
