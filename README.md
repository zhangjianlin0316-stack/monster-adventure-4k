# 灵兽冒险：翠风之旅

一款原创的回合制灵兽收集网页游戏，支持 4K 原生分辨率渲染，配有原创背景音乐和音效。

## 怎么玩
直接用浏览器打开 `index.html` 即可，无需安装。

| 按键 | 作用 |
|---|---|
| 方向键 / WASD | 移动、选择 |
| Z / 回车 / 空格 | 确认、对话 |
| X / Esc | 取消、打开菜单 |
| F | 全屏 |
| M | 静音 |
| - / = | 调节音量 |
