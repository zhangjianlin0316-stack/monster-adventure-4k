# 灵兽冒险：翠风之旅 v4（4K 原创收集养成 + 小学数学冲分）

一款完全原创的灵兽收集冒险网页游戏：原生 4K（3840×2160）画布渲染、原创音乐与音效、开放大地图，并把 **1–6 年级数学知识点和竞赛题** 深度融入战斗、捕捉、进化和探索的每一个环节。

**在线游玩：** https://zhangjianlin0316-stack.github.io/monster-adventure-4k/
（也可直接双击 `index.html` 本地打开，无需服务器）

## v4 新内容

- **火影风格战斗演出**（每个技能、每场战斗都重新设计）
  - 分级技能特写：普通技能有笔刷横幅 + 立绘特写 + 书法逐字招式名 + 朱印；招牌技加黑边与眼部特写条；终极招牌技更长
  - **奥义**：全屏过场 —— 泼墨转场 → 异空间背景（旋转光芒、灵力漩涡）→ 全身立绘 + 眼部特写 → 「奥义」朱印 + 竖排书法招式名 → 白闪，攻击时背景切换为暗色异空间、镜头旋转推进
  - **连击**：答对后普通招式化作 2~5 段连击（分段伤害、「N HITS 连击！」计数器），影分身、瞬身（消失 → 出现在对手身侧 → 斩击 → 闪回）等新动作
  - 冲击帧（反色 / 黑白集中线漫画帧）、击倒慢动作、冲击波、碎石、镜头旋转与推轨、灵气升腾、击退
  - **奥义槽**：答对 +25（神速 / 竞赛题再 +10），命中和受击也会充能；满槽后招式菜单出现【奥义】，需**连答两题**才能全力发动
  - 对手也会放奥义：出现「奥义防御」答题，答对结出灵力护盾，伤害降到 40%
- **灵兽扩充到 24 个系列、63 种**，新增稀有度 **普通 / 稀有 / 史诗 / 传说**（带颜色光环），**异色**灵兽（1/64，变色 + 闪光）
  - 新增：萤灯蛾、溪石獭、雪眠鸮、灵纹猫、苔石偶、墨鳞幼龙（三阶）；白羽鹤、锦鳞鲤、叶笛狸（二阶）；传说灵兽 霆角麒麟、天渊星鲸、烛炎神龙
  - 三处**传说神社**：通过金色竞赛试炼（3 题对 2 题）后传说灵兽才会现身
  - **灵兽图鉴**（菜单或按 P）：已见 / 已收服、稀有度、异色记录、能力值、招牌技、奥义、出没地点
- **星老师动画讲解**：答错时星老师出场，按知识点用动画一步步讲（凑十法、竖式、点阵、分组、钟表、人民币、分数饼图、线段图、天平、鸡兔同笼、行程、植树、抽屉原理等 30 种动画），可跳过（X）、可在错题本里按 H 重播
- **阴阳师风格原创音乐**：筝、三味线、尺八、龙笛、太鼓、钲、神乐铃、弦乐与现代节拍，都节 / 阳旋 / 平调子等日式五声调式；17 首主题（标题、城镇、7 个地区、普通 / 稀有 / 传说 / 训练师战斗、进化、胜利、讲解、答题），每轮自动变奏，低血量和奥义时音乐层次增强
- **更多技能**：每个属性新增进阶技能，进化形态各有 2 个以上招牌技 + 专属奥义；学第 5 个招式时可以选择遗忘哪一个；每个城镇有**招式导师**，通过数学挑战（3 题对 2 题）学招式

## v3 内容

- **数学是核心玩法**
  - 出招前答题：答对威力 ×1.3 起（连对越多越强，速答、竞赛题更强，并有暴击）；答错威力 ×0.6
  - 捕捉答题：答对捕获率 ×2.2（竞赛题 ×3）
  - 进化试炼：3 题答对 2 题才能进化
  - 地图上的数学门、断桥、谜题石：答对才能打开新区域
  - 宝箱、石碑、算术大师、训练师数学对决、黄金宝箱、幸运转盘
  - 连对奖励：每 5 连对送星星和双倍经验，每 10 连对抽一次幸运转盘
  - 错题本 + 同类题练习、知识点正确率统计、自适应难度、提示卡
- **数码风进化**：12 个系列 × 3 阶，共 36 种灵兽。每次进化有约 9 秒的变身动画（魔法阵、能量环、数学符号环绕、形态闪变、爆闪、新形态亮相、属性对比），进化后学会专属招牌技
- **更丰富的战斗动画**：每个招式都有独立的动画配方，包括施法动作、弹道、命中定格、镜头震动与推近、受击击退、残影、天气覆盖、速度线，招牌大招还有电影式特写
- **开放大地图**：150×110 格，7 大区域（翠风原野、赤砂峡谷等），多座城镇，小地图 + 世界地图（M 键），带探索迷雾和探索度统计
- 保留 v2 的全部内容：原创音乐、商店、治疗中心、存档读档等

| 4 | 大数的认识、运算定律与简便计算、小数的意义和加减法、角的度量、平均数 | 鸡兔同笼、盈亏、行程、和差、和倍、排列组合、巧算速算、数图形 |
| 5 | 小数乘除法、简易方程、因数与倍数、分数加减法、多边形的面积、长方体和正方体 | 抽屉原理、行程、盈亏、鸡兔同笼、排列组合、年龄问题、找规律 |

- 题目随机生成（含钟表、角、图形、扇形、圆柱等配图），另有 126 道精选竞赛题
- 每道题 4 个选项，可用键盘 1–4 或鼠标作答；答案全部经过独立验算（`node tests/mathq.test.js`）
- 在菜单「年级与竞赛」中可以随时切换年级、开启竞赛模式

## 操作

| 按键 | 作用 |
|---|---|
| 方向键 / WASD | 移动（按住 Shift 奔跑） |
| Z / Enter / 空格 | 确认、对话、调查 |
| X / Esc | 返回、打开菜单 |
| 1–4 | 选择答案 |
| H | 使用提示卡 |
| M | 世界地图 |
| Q | 错题本与统计（错题按 H 重播星老师讲解） |
| P | 灵兽图鉴 |
| → / 5 | 战斗中选择奥义（奥义槽满时） |
| F / V / − = | 全屏 / 静音 / 音量 |

鼠标也可以点击所有按钮和选项。
